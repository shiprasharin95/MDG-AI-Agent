# S23 custom development – MDG BP change request via OData

Everything to build in **S23, client 120**. Use package `ZMDG_AI` (or `$TMP` for a first test).

| # | Object | Type | Transaction | File |
|---|---|---|---|---|
| 1 | `ZCL_MDG_BP_CR_CREATE` | Class (creates the CR with `CL_USMD_GOV_API`) | SE24 / ADT | `ZCL_MDG_BP_CR_CREATE.abap` |
| 2 | `ZMDG_BP_CR_TEST` | Test report | SE38 | `ZMDG_BP_CR_TEST.abap` |
| 3 | `ZMDG_BP_CR` | Gateway project | SEGW | this file, section B |
| 4 | `ZCL_ZMDG_BP_CR_DPC_EXT` | Data provider class extension (generated by SEGW, then edited) | SE24 | `ZCL_ZMDG_BP_CR_DPC_EXT.abap` |
| 5 | `ZMDG_BP_CR_SRV` | Service registration | /IWFND/MAINT_SERVICE | section C |

## A. Class and test report (do this first)

1. Before activating, open **MDGIMG → Data Modeling → Edit Data Model → `BP`** and check that these entity types and attributes exist. Adjust the class if any differ.
   - `BP_HEADER` (BU_TYPE, BU_GROUP)
   - `BP_CENTRL` (NAME_ORG1, NAME_FIRST, NAME_LAST)
   - `ADDRNO`, `BP_ADDR`, `AD_POSTAL` (STREET, HOUSE_NUM1, POST_CODE1, CITY1, COUNTRY)
   - `BP_TAXNUM` (TAXTYPE, TAXNUM)
2. **SE24**: create class `ZCL_MDG_BP_CR_CREATE`, switch to the source-code-based editor, paste the class code and activate it.
   - If a method signature of `IF_USMD_GOV_API` differs in your release, check it with F2 or in ADT and adjust the call.
3. **SE38**: create report `ZMDG_BP_CR_TEST`, paste, activate and run it with F8.
   - `p_crtyp = ZBP1P1` with "Otto Willy / Teststraße 1 / 12345 Testhausen" should create a CR.
   - Check the result in transaction **`USMD_SSW`**, the **My Change Requests** app, or table `USMD120C`.
   - If ZBP1P1 fails, the class automatically retries with BP1P1, and the output shows a warning.

## B. SEGW project `ZMDG_BP_CR`

1. **SEGW** → Create Project → name `ZMDG_BP_CR`, project type Service with SAP Annotations, package `ZMDG_AI`.
2. Data Model → Entity Types → Create: **`ChangeRequest`**, with "Create related Entity Set" ticked → **`ChangeRequestSet`**.
3. Properties (all type `Edm.String`, all nullable except the key):

| Property | ABAP field | Max length | Key |
|---|---|---|---|
| CrNumber | CRNUMBER | 12 | X |
| CrType | CRTYPE | 12 | |
| CrStatus | CRSTATUS | 2 | |
| Description | DESCRIPTION | 60 | |
| BpCategory | BPCATEGORY | 1 | |
| Name | NAME | 80 | |
| Street | STREET | 60 | |
| HouseNumber | HOUSENUMBER | 10 | |
| PostalCode | POSTALCODE | 10 | |
| City | CITY | 40 | |
| Country | COUNTRY | 3 | |
| TaxType | TAXTYPE | 4 | |
| TaxNumber | TAXNUMBER | 20 | |
| BpTemp | BPTEMP | 10 | |
| Message | MESSAGE | 255 | |

4. Entity set `ChangeRequestSet`: tick **Creatable**, untick Updatable and Deletable.
5. Click **Generate Runtime Objects**. This creates `ZCL_ZMDG_BP_CR_MPC(_EXT)`, `ZCL_ZMDG_BP_CR_DPC(_EXT)`, model `ZMDG_BP_CR_MDL` and service `ZMDG_BP_CR_SRV`.
6. Open `ZCL_ZMDG_BP_CR_DPC_EXT` and redefine **`CHANGEREQUESTSET_CREATE_ENTITY`** and **`CHANGEREQUESTSET_GET_ENTITY`** with the code from `ZCL_ZMDG_BP_CR_DPC_EXT.abap`. Activate.

## C. Register and test the service

1. **/IWFND/MAINT_SERVICE** → Add Service → system alias `LOCAL` → technical service name `ZMDG_BP_CR_SRV` → Add (package `ZMDG_AI`).
2. **/IWFND/GW_CLIENT**:
   - GET `/sap/opu/odata/sap/ZMDG_BP_CR_SRV/$metadata?sap-client=120`
   - POST `/sap/opu/odata/sap/ZMDG_BP_CR_SRV/ChangeRequestSet?sap-client=120`, with header `Content-Type: application/json` and this body:
     ```json
     { "CrNumber":"", "CrType":"ZBP1P1", "BpCategory":"1", "Name":"Otto Willy",
       "Street":"Teststraße", "HouseNumber":"1", "PostalCode":"12345",
       "City":"Testhausen", "Country":"DE", "TaxType":"", "TaxNumber":"" }
     ```
   - The response should contain the `CrNumber`.
   - GET `/sap/opu/odata/sap/ZMDG_BP_CR_SRV/ChangeRequestSet('<CrNumber>')?sap-client=120` returns the CR status.
3. Error log: transactions **/IWFND/ERROR_LOG** and **/IWBEP/ERROR_LOG**.

## D. Authorizations for the user that BTP / CAP uses

- `S_SERVICE` for `ZMDG_BP_CR_SRV` and `API_BUSINESS_PARTNER`.
- BP display authorizations (`B_BUPA_GRP`, `B_BUPA_RLT`) for the duplicate check.
- MDG BP requester authorization for CR types ZBP1P1 and BP1P1. Copy your MDG BP requester role in PFCG; the exact role name depends on your release.
